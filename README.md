# Misi Integriti — Fail 5W1H

Permainan pembelajaran Bahasa Melayu berasaskan tugasan Kumpulan 1: Penilaian Kualiti Maklumat Menggunakan 5W1H.

Pemain menjadi pegawai Unit Integriti, bergerak melalui enam lokasi, memilih soalan susulan, menyemak bukti dan menyelesaikan tiga senario keputusan. Sepuluh cabaran membawa maksimum 100 markah. Markah diberikan hanya untuk jawapan pertama yang tepat. Jawapan salah boleh dicuba semula untuk pembelajaran.

## Kandungan

- `dist/index.html`: halaman permainan dan taklimat
- `dist/styles.css`: tema, peta dan paparan responsif
- `dist/game.js`: jalan cerita, logik permainan dan pemarkahan
- `dist/office.png`: latar pejabat
- `.openai/hosting.json`: konfigurasi Sites

Jalankan pelayan fail statik pada folder `dist` untuk pratonton. Tiada pemasangan pakej atau proses binaan diperlukan. Font luaran mempunyai fallback fon sistem. Tiada akaun pemain, pengumpulan data atau pelayan aplikasi.

## Asas kandungan

Soalan tugasan dan `Tugasan_Akhir_Kumpulan_1_5W1H.pptx` yang diberikan pengguna. Nama, tarikh, nilai dan peristiwa tambahan ialah rekaan untuk simulasi. Tiga keputusan mengikut rangka jawapan kumpulan, bukan pengganti prosedur rasmi mana-mana agensi.

## Aliran

Taklimat → WHO → WHAT → WHEN → WHERE → WHY → HOW → bukti dan sumber → aduan terlalu umum → maklumat sebahagian → lengkap dan bukti awal → laporan markah dan ulang kaji.
